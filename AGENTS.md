# Game text

Use the user's AJN Aokane font for all existing and new game text.
Use `Assets/font/ajn-aokane.otf/ajn-aokane SDF.asset` for TextMeshPro,
with the source font at `Assets/font/ajn-aokane.otf/ajn-aokane.otf`.
Keep editor setup tools and the TMP default font consistent with this choice.
Preserve the supplied font and license files. This font has no multiplication
sign glyph, so use ASCII `X` in combo labels.

Use the supplied original K.O. emblems, knockout animation artwork, and WATCH OUT
texture for those graphical status indicators, as requested by the user. Dynamic
labels, ranks, counters, and other game text still use AJN Aokane.
