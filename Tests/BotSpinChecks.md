Run `BotSpinChecks.Run` with Unity `-batchmode -nographics -projectPath <isolated-project> -executeMethod BotSpinChecks.Run -logFile <log>` after copying current gameplay scripts and `BotSpinChecks.cs` into the isolated project. Success logs `BOT_SPIN_CHECKS_PASSED` and exits zero.

The checks use the real bot BFS, board, SRS, and combat components. Fixed reachable full-single/full-double fixtures must send two/four lines; a mini-single fixture captured from an honest seven-bag game must send zero and establish back-to-back. Each lock must add four non-overlapping cells, preserve the stack, retain its spin through the clear delay and pause, then compact and send its attack exactly once. Real SRS rotations followed by down/right translations into a three-corner cavity must lose spin eligibility. Reset clears stored spin and combat-chain state. No scene or prefab assets are changed.
