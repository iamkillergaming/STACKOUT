`ClearAttackFeedbackChecks.cs` exercises the final authored clear callouts, attack stars, sounds, and supplied ajn-aokane font. Copy it into `Assets` in an isolated copy of the project after running `FeedbackSceneSetup`; then run Unity 6000.3.8f1 with `-batchmode -force-glcore -screen-width 1920 -screen-height 1080 -projectPath <isolated-project> -executeMethod ClearAttackFeedbackChecks.Run -logFile <log>`. Omit `-quit` and `-nographics`: the fixture enters Play mode, captures a live 1920×1080 image, and exits itself. Success logs `CLEAR_ATTACK_FEEDBACK_CHECKS_PASSED`; setup or coroutine failures exit with code 1.

The check expects the final one-opponent SampleScene. It instantiates a second saved bot prefab in existing slot 49, holds gravity and automatic bot turns, and saves only `Assets/ClearAttackFeedbackChecks.unity` in the isolated project. It never saves SampleScene or a prefab. Both opponents receive four actual AI placements for the screenshot, using four queued O pieces to avoid incidental garbage attacks during setup.
